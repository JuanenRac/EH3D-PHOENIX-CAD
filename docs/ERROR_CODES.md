# EH3D-PHOENIX-CAD: diagnostic codes

Codes have the form `PHOENIX-<AREA>-<NNN>`. A code is stable: it never changes its meaning and is never reused. Programs show the text through the key `diag.<code>`; the codes themselves are never translated.

The table repeats the `REGISTRY` of the crate `eh3d-phoenix-cad` (`src/lib.rs`); a test checks that every code of the registry is in the table with the same title.

## Mechanical model

| Code | Title | Raised by |
|---|---|---|
| PHOENIX-CAD-001 | Length outside the mechanical range | a length whose absolute value is not below 2^40 nanometres, or an outer size that would leave the range |
| PHOENIX-CAD-002 | Parameter is not positive | a size, wall, floor, lid or hole diameter that is zero or negative, or a margin or web that is negative |
| PHOENIX-CAD-003 | Hole outside its face | a hole that does not lie inside its face with the margin from the edges |
| PHOENIX-CAD-004 | Holes too close | two holes of one face with less than the minimum web between them |
| PHOENIX-CAD-005 | Hole or post id used twice or unknown | an operation that adds a hole, a post, an extrusion or a pocket under an id already used, or names a hole, a post, an extrusion or a pocket that does not exist |
| PHOENIX-CAD-006 | Angle outside the range | an angle whose absolute value is not below a million degrees |
| PHOENIX-CAD-007 | Count or ratio outside its range | a count that is negative or above a million, or a ratio beyond a thousand times the whole |
| PHOENIX-CAD-008 | Number with a unit not understood | a text such as `1.6 mm` or `1/16 in` that has no number, no known unit or an invalid fraction |
| PHOENIX-CAD-009 | Integer calculation overflows | a scaling or a division that does not fit in the integers used, or a division by zero |
| PHOENIX-CAD-010 | Reference to an element that does not exist | a name of a face, edge or hole wall that is unknown, names a hole that is gone, or is not written in the canonical way; the operation that uses it fails and no other element is chosen in its place |
| PHOENIX-CAD-011 | Settings not valid | a settings file with a line that is not a section, a `key = value` or a comment, a repeated or missing key, or a value outside its limits; the message names the line or the key |
| PHOENIX-CAD-012 | File cannot be read or written | a file that cannot be created, read, replaced or copied, or that is larger than the limit given to the loader; a failed save leaves the old file as it was |
| PHOENIX-CAD-013 | Dependency cycle | a dependency that would make an object depend on itself, directly or through others, including a parameter whose expression refers to itself or to a parameter that refers back to it; the graph is left as it was |
| PHOENIX-CAD-014 | Unknown name or id | an id, a variable, a variant or a domain that does not exist, or a name in an expression that is no parameter, variable or constant (the message gives the column) |
| PHOENIX-CAD-015 | Name or id already used | an object, a variable or a variant added under a name or an id that is taken |
| PHOENIX-CAD-016 | Object still in use | an object removed while others still depend on it |
| PHOENIX-CAD-017 | Name not valid | a variable, a variant or a binding named with something other than a letter followed by letters, digits and underscores (up to 64 characters) |
| PHOENIX-CAD-018 | Project file not valid | a project file with a wrong header, a version that is zero or newer than this program, a domain that is repeated, cut short or badly named, or a size above the limit; also the domain `mechanical` with a version and steps that do not agree (a step of a newer version than the header says, or a header of a version that no step needs) |
| PHOENIX-CAD-019 | Edge treatment not valid | a rounded or chamfered edge whose size is larger than half of the box, that reaches the inner space, or whose lid and floor treatments are together higher than the box; the model is left as it was |
| PHOENIX-CAD-020 | Hole shape not valid | a countersink or counterbore that is not wider than its hole or that is as deep as the material, a counterbore depth that is not positive, a rectangle without height, or a slot shorter than it is wide; the model is left as it was |
| PHOENIX-CAD-021 | Screw size not in the table | a screw named in a request that the table of screws of the settings does not have |
| PHOENIX-CAD-022 | Shape not drawn by this export | a model with rounded or chamfered edges or with a countersunk, counterbored, rectangular or oval hole, asked of the STEP export, which draws only the box with straight round holes; the script export draws all of them; also a model with an extrusion or a pocket of a sketch, asked of the STEP export or of the model for fabrication (the script says in a comment that it does not draw them) |
| PHOENIX-CAD-023 | Expression not valid | an expression of a parameter that is not written in the language: a character that does not belong, a number with more than 18 digits, a missing parenthesis or operand, an unknown function, the wrong number of arguments, a comparison chained with another, a unit without a number; the message gives the column |
| PHOENIX-CAD-024 | Expression cannot be evaluated | an expression that is well written but makes no calculation: a length added to a number, two lengths multiplied, a division by zero, a square root that is not exact, a power with a length or a fraction as exponent, a condition that is not true or false, a result that is not a length where a length is needed; the message gives the column of the operation |
| PHOENIX-CAD-025 | Expression limit exceeded | an expression longer than the limit, nested deeper than the limit, that needs more steps than the limit allows, or with an exponent above the limit; the limits are the `[expr]` keys of the settings file |
| PHOENIX-CAD-026 | Expression arithmetic overflows | an operation of an expression whose exact result does not fit in the 128-bit numbers used (a product, a sum, a power or a comparison); the message gives the column of the operation |
| PHOENIX-CAD-027 | Post shape not valid | a post whose bore is not narrower than the post or is deeper than the post is high, whose foot is not wider than the post or is as high as the post, a post made for a board hole narrower than the thread of its screw, or whose wall around the bore is thinner than the least wall of the settings |
| PHOENIX-CAD-028 | Post meets a wall, a post or a hole | a post whose footprint (the foot when it is wider) crosses a wall of the inner space, overlaps another post or crosses a hole of the floor, or a board that does not lie inside the inner space; touching is allowed, overlapping is not |
| PHOENIX-CAD-029 | Post too high for the space above it | a post that is not lower than the inner height, or posts, board and tallest part together higher than the inner height; the message gives the figures |
| PHOENIX-CAD-030 | Lid fixing not valid | a lid fixing with a head that is not round (a rectangle or a slot), a corner inset that leaves no room between the screws, a centring lip as deep as the inner space or that leaves no opening, or a post that reaches the lip and meets it; the holes of the lid are also checked as any other hole and give their own codes |
| PHOENIX-CAD-031 | Sketch element not valid | a line, circle or arc made of something that is not a point, a line between a point and itself, a circle without a positive radius, a polyline with too few points, a rectangle without width or height, a point of the model that is not in the plane of the sketch, or an element that does not hold together in a sketch file; an element that another element or a constraint still uses is `PHOENIX-CAD-016` |
| PHOENIX-CAD-032 | Sketch constraint not valid | a constraint about elements of the wrong kind (a horizontal constraint on a point, a tangent between two lines, an equal between a line and a circle), tied to the same element twice, a dimension that must be positive and is not, or an expression of a dimension that cannot be calculated (the message names the constraint and carries the error of the expression) |
| PHOENIX-CAD-033 | Sketch over-constrained | constraints that add nothing to the ones before them: listed as redundant when the sketch has a solution and as in conflict when it has none, each with the earlier constraints it depends on; the sketch is left as it was |
| PHOENIX-CAD-034 | Sketch solver did not converge | the solver used all its steps or could not get nearer to a solution without being at a conflict (the message gives the steps and the largest residual); the sketch is left as it was |
| PHOENIX-CAD-035 | Sketch file not valid | a sketch file that is not text, is of a newer version, has a line that is not understood, describes a sketch that does not hold together, or is larger than the settings allow; the message gives the line; also the domain `sketch` of a project file that is of a newer version, damaged, not in the one canonical form, has two sketches of one name or more sketches than the settings allow, where the message names the sketch |
| PHOENIX-CAD-036 | Profile of the sketch not valid | a sketch from which no closed outline can be taken: no line, arc or circle that is not construction, a chain that does not close or that branches at a point, a line or arc that ends on itself, an outline that crosses or touches itself or another one, or an outline smaller than the least area of the settings (`profile_min_area`); the message says where |
| PHOENIX-CAD-037 | Extrusion or pocket not valid | an extrusion or a pocket of a sketch that does not exist, whose plane is not on the face or has an offset, whose outline does not lie inside the face (inside the margin of the edges for a pocket), with a height that is not positive, or a pocket deeper than the material of the face; the model is left as it was |
| PHOENIX-CAD-038 | Measurement not valid | a measurement that cannot be made: an edge with no length, an angle whose lines have no length (two of the three points are the same), an angle at a vertex asked of edges or an angle between edges asked of points, or the wrong number of references; the readings kept are left as they were |
| PHOENIX-CAD-039 | Drag not possible | a hole or a post that is dragged in a view that shows the plane of the object edge on (a face seen from the side, so a point of the pane does not say where on the face it is); the model is left as it was, and the view is turned or moved instead |
| PHOENIX-CAD-040 | File exists and was not written over | a file that is not written from the window because one with that name is already there and the box to write over it was not ticked; the file is left as it was |
| PHOENIX-CAD-041 | Export not possible | a file that cannot be written from the window: a name that ends in the extension of a project or of a sketch, the file of the project that is open, a folder, a folder that does not exist, a text larger than the largest export of the settings (`export.max_kib`) or a writing that failed (no half-written file is left); the project is left as it was |
| PHOENIX-CAD-042 | Pattern not valid | a pattern of holes or posts with fewer than two positions or more than the largest count of the settings (`pattern.max_count`), a step of nothing or an angle of nothing, a circle whose seed is at its centre, or a change to one position of a pattern on its own (the pattern is edited as a whole); a position that the model refuses (outside the face, too near another hole, a post that meets a wall) keeps the code of that refusal, with the name of the position, and the pattern is not added at all |
| PHOENIX-CAD-043 | Cooling fins not valid | a set of cooling fins with no fin or more than the largest count of the settings (`fins.max_count`), thinner than `fins.min_thickness`, taller than `fins.max_height_ratio` times their thickness, with less air between two fins than `fins.min_gap` (or between two sets on a face), with a height or a length that is not positive, whose footprint does not lie inside the face with the margin of its edges and the treatment of its edges, or that leaves less than the least web to a hole of the face (the holes of the lid fixing among them); a hole, a post or a lid fixing that would put a hole in the way of a set, a box that becomes too small for it, and a change of the edges that takes the room away are refused with this code, and the model is left as it was |
| PHOENIX-CAD-044 | Library of parts not valid | a library file (`.phoenixlib`) that is not a library, is of a newer version than the program reads, has a line that is not understood or a number that is not a whole count of nanometres, lists a part twice, has a part that does not hold together (a hollow section with no room inside, a usual cut longer than the bar, a head not wider than its shank, a hole that does not fit a leg, a size above `catalog.max_dimension`), a material that is not in the settings, more parts than `catalog.max_parts` or more bytes than `catalog.max_bytes`; the number of the line is in the detail
| PHOENIX-CAD-045 | Part not valid | a part placed in the model whose cut is shorter than `catalog.min_cut` or longer than its bar, a cut given to a part that is not a profile or missing on a profile, a part that lies farther from the origin than `catalog.max_dimension`, a profile that shares volume with another one (when `catalog.refuse_profile_overlap` is 1), more parts than `catalog.max_instances`, or a bill of materials asked for a material that has no density in the settings; the model is left as it was
| PHOENIX-CAD-046 | Assembly not valid | a mate that names a part that is not in the model, joins a part to itself, places a part by two mates along one axis, makes a cycle with other mates, aligns the middles of two parts that differ by half a nanometre, leaves a part outside the range of lengths or farther from the origin than `catalog.max_dimension`, has a gap that is negative or larger than that, or is one more than `assembly.max_mates`; taking away a part that a mate uses is refused with this code too; the model is left as it was |
| PHOENIX-CAD-047 | Parts interfere | the pairs of placed parts that share volume, as the `interference` command and the report of the window give them (the parts with their mates applied; a pair that only touches is not in conflict, and a screw through the hole of a bracket is a pass, not a conflict); it is a finding that is reported, not a refusal of a step |
| PHOENIX-CAD-048 | Shape the solid cannot be made of | a model that the STL file cannot be made of, with the name of the shape and of the one it meets: rounded or chamfered edges around the lid or the floor, a hole or a pocket through the face that is not inside the thin part of its face, an extrusion, a fin or a pocket that touches the edge of its face, shapes of one face that cross or touch each other, a post that meets a wall, another post or a hole of the floor, a lip that meets a hole of the lid (see [EXPORT.md](EXPORT.md)) |
| PHOENIX-CAD-049 | Solid does not match the model | a solid whose surface is not closed (an edge that is not used by exactly two triangles) or whose volume is farther from the exact volume of the model than `mesh.volume_tolerance_ppm` parts per million; nothing is written |
| PHOENIX-CAD-050 | Export above the limits | a solid with more triangles than `mesh.max_triangles` or a drawing with more entities than `drawing.max_entities` |
